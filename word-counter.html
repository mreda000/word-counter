Exactly what the counters measure

Different writing apps can use different counting rules. If a school, employer, or submission form sets a strict limit, check the final text in that system too.

Words
One word is one nonempty group separated by spaces, tabs, or line breaks. Numbers and standalone punctuation can count as words. Hyphenated words and contractions stay together. Languages normally written without spaces will not be segmented into individual words by this counter.
Characters
The count includes spaces, tabs, punctuation, and line breaks, including whitespace at the start and end. It measures JavaScript text units (UTF-16), so an emoji or a combined character can contribute more than one unit. This is not a universal count of visible symbols.
Numbers
This counts groups of digits with word boundaries, rather than mathematical values. 12 counts as one group; 3.5 and 1,000 each count as two. 2nd does not count because letters touch the digits. A minus sign is not part of the number group.
Sentences
Periods, question marks, and exclamation marks split the text into nonempty segments. A final segment without punctuation still counts. Abbreviations and decimal points can split a sentence unexpectedly; this is a simple estimate, not a grammar parser.
Paragraphs
Each nonempty line counts as a paragraph, whether there is one line break or several between lines. A line wrapping visually inside the editor does not add a paragraph. Text copied with a hard line break after every line may therefore show more paragraphs than your source document.

Use time and reading grade as estimates

Reading and speaking time

Reading time is words ÷ 200 × 60 seconds. Speaking time is words ÷ 130 × 60 seconds. Durations are rounded to the nearest second; a nonempty draft displays at least one second. These are fixed planning assumptions, not a measurement of your own pace.

A 390-word speech gives an estimated speaking time of 3 minutes at 130 words per minute. Pauses, slide changes, audience reactions, and emphasis can make the real delivery longer. Read your own draft aloud with a timer before relying on a limit. The speech timing guide shows how to budget for pauses.

Estimated English reading grade

The score uses this calculation: 0.39 × words per sentence + 11.8 × syllables per word − 15.59. For this estimate, the tool keeps tokens containing English A–Z letters and approximates syllables from vowel groups, with a simple final-e adjustment. The result is rounded to a whole number and values below zero display as zero.

This approximation can miscount names, abbreviations, technical terms, and non-English text. Very short samples can produce unstable scores. A lower number does not prove that an explanation is clear, and the score does not assess accuracy, tone, accessibility, or suitability for a particular reader. Use the reading-level editing example to compare a revision, then read it yourself.

When “Fetch & Analyze” works—and when to paste instead

Enter a complete https:// or http:// address. Your browser requests that page directly. The tool accepts HTML or plain text; for HTML it removes common navigation, header, footer, script, and style elements, then uses a main or article area when available. HTML whitespace is collapsed, so fetched paragraph counts may differ from the visible article.

Why does a public webpage fail to load?

Many websites do not allow another website to read their pages through a browser request (CORS). A link opening normally in a new tab does not mean this tool can fetch it. Copy the article text and paste it into the editor instead. This feature does not bypass paywalls or sign-in requirements.

Why is the imported text incomplete or different?

Some pages build their content with JavaScript after loading. This tool analyzes the returned HTML; it does not run the source page's scripts or reconstruct its visual layout. Menus, captions, or unrelated text may still be included. Review and edit the imported text before using its count.

Can I analyze a PDF or an image URL?

The URL field does not extract text from PDFs or images. Copy selectable text from a document into the editor. For an image of printed English text, try Image to Text, proofread the recognition result, then send it to this counter. See the webpage import guide for more examples.

What happens to your text

Counting and analysis run in your browser; the analyzer does not upload your draft to a ChickenTask server. The editor does not intentionally save drafts, and clearing the editor removes its current contents. If you arrive from Image to Text, its transfer uses this tab's session storage and the transfer item is removed after it is read.

Fetching a URL contacts the website you entered. Advertising, sign-in, and optional analytics have separate data practices explained in the Privacy Policy. Avoid putting sensitive information into a public webpage URL.
